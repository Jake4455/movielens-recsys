## 3. 表注（负结果与口径说明）

1. **两种难负样本均无效**（同一 16 特征管线下的三臂对照）：R10（hard_ratio=0）0.8587 > R09（流行难负）0.8518 > R11（真实负反馈）0.8224。修复口径后差距**扩大了**（R09−R10 由 −0.0020 变为 −0.0069，R11−R10 由 −0.0242 变为 −0.0363）：均匀负样本里本来就有 18.5% 是训练期零热度的冷门项，用热门项替换 20 个均匀负样本造成的冷热错配比之前更严重。
2. **R11 在第 4 轮就早停**（best_iter=4，上限 300）：真实负反馈把"用户已看但评分 < 4"的项当负样本，而测试候选完全排除已交互项，模型几乎立刻学不到可迁移信号。这与"该方向不可取"的结论一致，且证据比修复前更强。
3. **图特征 `graph_walk2` 与 `graph_community_affinity` 无效**（未进入 R08）：walk 在训练期被用户自身共现边抬高，Louvain 社区特征数值近乎恒 0 却异常主导。两者已关闭，仅保留 PageRank（数值为 2026-09-16 修复前口径，本轮未重跑；当前配置关闭）。
4. **F3 绝对值口径退化**：近 7/30/90 天绝对计数把"年代整体活跃度"编码进来，训练/测试时间尺度漂移导致 best_iter=1；改为比值型后泛化（该对照为 2026-09-16 历史测量，未随本轮重跑，仅作口径方向说明）。
5. **R01/R02（召回）不进入 leaderboard**：本协议下召回率不决定 NDCG，ItemCF 与 SimHash 以"准确率—效率"报告为证据（`outputs/reports/recall_lsh.md`），结论为本规模下 LSH 无净收益。
6. **延迟有两个口径，均可查**：`推理延迟` = 仅打分/预测耗时 / 测试用户数（写入 `outputs/top10/<run>_meta.json`，`latency_scope: inference_only`）；`管线延迟` = 该 run 阶段总耗时 / 测试用户数（写入 `outputs/leaderboard.csv` 的 `latency_ms`，含特征生成与批量推理）。两者都不是在线单请求服务延迟。
7. **R09/R11 为 16 特征版且同种子**，与 R10 仅差 `hard_ratio` 与 hard 源，可直接对比。
8. **中间臂的 lift 低于 1.1**：R06/R07/R08/R11 分别为 1.0882/1.0878/1.0893/1.0906。协议达标判据（lift ≥ 1.1 且 CI 下界 > 0）只适用于**最终模型**（R13：1.1575，CI 下界 +0.1177），中间臂是消融阶梯而非提交臂。
9. **早停缺陷（2026-10-08 发现）**：R12 与 R13 使用**完全相同**的特征与超参，唯一差别是早停开关 —— 开：`best_iter=1`、test 0.829605；关（固定 300 轮）：`best_iter=300`、test 0.872787，**相差 0.043 NDCG**。根因是 LightGBM 内部验证指标按**行序**打破并列分数，而 `build_groups` 把每个用户的正样本放在该组第 1 行；`itemcf_max_sim` 有 96% 取值为 0，前几轮产生大量并列 → 内部 NDCG 被"正样本因行序靠前而恒列第一"抬高（第 50 轮内部报 0.8866，而官方口径仅 0.8519）→ 早停锁定第 1 轮，模型只有 1 棵树。关闭早停后并列消失，内部指标与官方指标完全一致（均 0.891305）。**该缺陷同样可能拖累 R10（其 best_iter=213/300）**，"R10 + 固定轮数"的拆分实验列入待办。
