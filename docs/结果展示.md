## 六、复现方式

```bash
# 1. 获取代码
git clone https://github.com/Jake4455/movielens-recsys.git   # 私有仓库，需授权
# 2. 下载 MovieLens 32M 并解压到 data/ml-32m/（原始数据未随仓库提交）
# 3. 安装依赖
conda create -n mlrecsys python=3.11 -y && conda activate mlrecsys && pip install -r requirements.txt
# 4. 复现最终模型（17 特征 + 固定 300 轮）
python run_all.py --config conf/itemcf_noes.yaml --stages stream,ltr --force
# 5. 评测与测试
python -m pytest tests -q
```

## 七、可信度说明与已知边界

1. **口径修复**：候选集负采样曾因 `np.unique` 截断而偏离"均匀随机"文档口径（约 51% 目录不可达），2026-10-08 修复后**全臂重跑**；修复前 lift 曾虚高为 +23.56%，现为真实的 +15.75%。
2. **早停缺陷**：LightGBM 内部验证指标按行序打破并列，而训练组把正样本置于每组首行；同一组特征开早停仅 0.8296、关闭早停得 0.8728。最终模型因此采用固定 300 轮。
3. **归因待补**：R13 的 +0.014126 同时包含"新增召回特征"与"关闭早停"两项改动，尚未拆分（R14 拆分实验待跑）。
4. **协议口径**：教师端候选集生成规则与评测脚本相关性定义（Q1/Q6/Q7）尚未确认；本地按"全库均匀随机 + 排除用户已交互项"复现。
5. **分布式程度**：Spark 运行于单机 `local[8]`（伪分布式），扩展性结论不代表真实集群。
6. **诚实记录**：如实记录 5 类负结果（两种难负样本、绝对时间口径、随机游走/社区特征、LSH 无净收益、移植特征边际为负）与早停陷阱的定位过程，全部可复核。
